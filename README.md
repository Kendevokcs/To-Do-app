MaybeTomorrow – To-Do Weboldal

A **MaybeTomorrow** egy letisztult, gyors és egyszerű to-do webalkalmazás, amely a felhőalapú Google Firebase háttérrendszerre épülve biztosítja a mindennapi teendők azonnali rögzítését és követését felesleges bonyolítás nélkül.

##  Fejlesztők és feladatkörök
* **Kugyela Kende** – Projektvezető, HTML (frontend)
* **Hanzel András** – CSS (frontend / stílus)
* **Kovács Bálint** – JavaScript (klienslogika, Firebase backend)

##  Főbb funkciók
* Új feladat felvétele szöveges beviteli mezőből.
* Feladat elvégzettnek jelölése egy kattintással.
* Feladat végleges törlése a listából.
* Valós idejű, felhőalapú szinkronizáció és adattárolás (Google Firebase).

> **Megjegyzés / Korlátozások:** A felület szándékosan minimális: a teendők utólagos szövegszerkesztése, valamint a szűrés és keresés nem képezi az alkalmazás részét.

##  Alkalmazott technológiák
* **Frontend:** HTML5, CSS3
* **Logika:** JavaScript
* **Backend & Adatbázis:** Google Firebase
